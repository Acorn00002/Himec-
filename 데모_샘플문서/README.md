# 라이브 데모용 샘플 설계문서

가상 프로젝트: **△△ 폐수처리시설 개선사업 — 이송펌프 패키지**
실제 파일 분석 경로(새 프로젝트 → 업로드 → 교차검증)를 시연하기 위한 문서 4종입니다.
데모 프로젝트와 달리 **실제로 파싱하고 Gemini가 추출**합니다.

| 파일 | 형식 | 발행 부서(가정) | 표기 |
|---|---|---|---|
| `01_기계장비_사양서.pdf` | PDF | 기계설계팀 | 한글 ("정격출력") |
| `02_전기_부하계산서.csv` | CSV(표) | 전기팀 | 영문 ("Power(kW)") |
| `03_전기_단선결선도_주석.txt` | TXT | 전기팀 | 영문 ("RATED OUTPUT") |
| `04_설비_목록.csv` | CSV(표) | 프로젝트 | 한/영 혼용 ("정격출력(kW)") |

## 사용법
1. 앱에서 **새 프로젝트** 생성
2. **문서 업로드** 화면에 위 4개 파일을 한 번에 끌어다 놓기 (문서 종류는 대략만 맞춰도 됨)
3. **교차검증 실행**
4. **대시보드 / 설비 탐색**에서 결과 확인

## 심어둔 불일치 (정답셋 5건)

| 설비 | 항목 | 사양서 | 부하계산서 | 도면 | 설비목록 | 유형 |
|---|---|---|---|---|---|---|
| P-101 | 정격출력 | 15 kW | 15 kW | **18.5 kW** | 15 kW | 도면 오기재 |
| P-101 | 정격전압 | 380 V | 380 V | **440 V** | 380 V | 도면 오기재 |
| P-101 | 케이블 규격 | (참고) | 25 mm² | 25 mm² | **35 mm²** | 설비목록 미갱신 |
| M-101 | 모델명 | **SM-132M** | - | - | **SM-132S** | 한 글자(프레임 상이) |
| P-102 | 양정 | 45 m | 없음 | 없음 | 없음 | 예비설비 사양 누락 |

## 시연 포인트
- **이기종·다국어 통합**: 한글 사양서 + 영문 도면 + Excel 표에서 동일 TAG(P-101 등)를 자동 연결
- **표기 정규화**: "정격출력 = RATED OUTPUT = Power(kW)", "m³/h = m3/h", "4C x 25 SQMM = 25 mm²"
- **놓치기 쉬운 것**: SM-132M vs SM-132S (한 글자), 유량 근소차
- **추적성**: 값 클릭 → 원문 문장 확인
- **Human-in-the-Loop**: 이슈에 "조치 필요 / 의도된 차이" 상태 + 검토 의견 → PDF 리포트 반영

## 부록: 단일 문서 테스트 (`05_단일문서_테스트_사양서.pdf`)

문서를 여러 개 준비하지 않고 파이프라인만 빠르게 확인하고 싶을 때 이 **1개 파일**만 업로드.
교차검증은 보통 2개 이상 문서가 필요하지만, **한 설비 안에서 값들이 서로 맞는지(계산 검증)**와
**필수 항목 누락**은 문서 1건으로도 잡아냅니다.

| 예상 이슈 | 설비 | 내용 |
|---|---|---|
| 높음 | M-301 | 차단기 20 A < 정격전류 28 A → 과전류 보호 여유 부족 |
| 중간 | P-301 | 정격전류 32 A vs 30kW·380V 계산값 약 44 A |
| 낮음 | M-301 | 효율(전동기 필수 항목) 누락 |
| 낮음 | B-301 | 유량(송풍기 필수 항목) 누락 |

## 재생성
- `_generate.py` — 이기종 4문서 (백엔드 venv 파이썬으로 실행)
- `_generate_single.py` — 단일 문서 테스트 파일
- `_generate_additional.py` — 공정 데이터·계장 데이터시트·변경이력 3문서 추가 생성
값·불일치를 바꾸려면 해당 스크립트를 수정하세요.

## 추가 테스트 문서

기본 4종에 더해 아래 3종을 함께 업로드하면, 서로 다른 문서 형식뿐 아니라
공정 조건과 변경 메모가 설비 정보에 미치는 영향도 함께 확인할 수 있습니다.

| 파일 | 형식 | 테스트 목적 |
|---|---|---|
| `06_공정_설계데이터.csv` | CSV | 유량 120/125 m³/h 차이 및 공정 기준 비교 |
| `07_계장_모터데이터시트.pdf` | PDF | 전기·계장 인터페이스 값과 케이블/차단기 비교 |
| `08_설계_변경이력_검토메모.txt` | TXT | 변경 사유·검토 메모의 원문 추적 |

실제 데모에서는 **기본 4종 + 추가 3종**, 총 7개 파일을 한 번에 업로드하면 됩니다.

# 기대효과 정량 모델

> 채점 항목: 활용성·기대효과 (배점 20)
> ⚠️ 아래 숫자는 **보수적 예시**입니다. 사내 실제 프로젝트 규모를 대입해 확정하세요.

---

## 1. 시간 절감 모델

### 변수 정의
| 기호 | 의미 | 예시값(보수적) |
|---|---|---|
| E | 검토 대상 설비 수 (1개 패키지) | 40 |
| D | 설비당 관련 문서 종류 | 5 (사양서·계산서·도면·목록·P&ID) |
| P | 설비당 교차 확인할 핵심 파라미터 | 8 (출력·전압·전류·모델·유량·양정·케이블·차단기) |
| t_manual | 파라미터 1건을 문서 간 수동 대조하는 시간 | 1.5분 |
| t_review | AI가 찾아준 이슈 1건을 엔지니어가 판단하는 시간 | 5분 |
| r | 실제 이슈 발생률 (전체 확인 건수 대비) | 3% |

### 계산
```
전체 확인 건수      = E × P                     = 40 × 8   = 320건
수동 교차검토 시간   = E × P × t_manual           = 320 × 1.5분 = 480분 ≈ 8.0시간
AI 발견 이슈 수      = E × P × r                  = 320 × 0.03 = 9.6건 ≈ 10건
AI 사용 시 검토 시간 = (AI 발견 이슈 × t_review)   = 10 × 5분   = 50분 ≈ 0.8시간
                     + 결과 훑어보기 30분          → 약 1.3시간
```

| | 수동 | AI 지원 | 절감 |
|---|---|---|---|
| 1개 패키지 교차검토 | **8.0시간** | **1.3시간** | **약 84%** |

- 프로젝트당 패키지가 10개면: 80시간 → 13시간 (엔지니어 약 2주 → 2일)
- 절감된 시간은 **대조 작업이 아니라 설계 품질 검토·의사결정**에 재투입 (공모전 취지 ①의 "고차원 업무 집중")

## 2. 리스크 절감 모델 (재시공 방지)

### 논리
- 문서 불일치 1건이 **시공 단계까지 통과**하면: 자재 재발주 + 재시공 + 공정 지연.
- 건설 산업의 재작업(rework) 비용은 일반적으로 프로젝트 원가의 상당 비중을 차지하며, 그중 다수가 **설계·문서 조정 오류**에서 비롯된다. (→ 사내 실제 재시공 사례 1건의 비용을 여기 대입)

### 기대값 계산 (예시)
```
연간 프로젝트 수                        = N
프로젝트당 시공까지 새어나가는 불일치     = f 건   (보수적으로 1건)
불일치 1건당 재시공 손실                = C 원    (사내 사례 기준)
시스템 탐지율                          = 90%

연간 기대 절감 = N × f × C × 0.90
```
- 재시공 **단 1건**만 예방해도 절감액이 도입·운영 비용을 상회하는 구조 (건설 재시공 1건은 통상 수백만~수억 원).

## 3. 적용 범위 · 확산 가능성

| 축 | 내용 |
|---|---|
| 공종 | 전기 · 기계 · 배관 · 계장 (부서 간 데이터 통합이 곧 본 시스템의 기능) |
| 단계 | 상세설계 → 설계검토(IDC) → 구매사양 확정 → 준공도서 정합성 |
| 재사용 | 프로젝트마다 반복 사용. 프로젝트/현장에 독립적 |
| 확장 | 같은 검증 엔진에 **파서만 추가**하면 CAD·BIM·스캔 도면으로 확대 |
| 조직 | 사내 표준 검토 툴 → 협력사 산출물 검수에도 적용 |

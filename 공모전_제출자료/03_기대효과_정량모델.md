# 기대효과 측정 계획

2026-09-13 검토: 현업 시간 절감률과 재작업 비용 절감액은 아직 검증되지 않았다.

## 기존 데모 기록

기존 자료에는 합성 문서 4건·설비 3개에 대해 업로드/추출 27.9초, 교차검증 35.1초, 합계 약 63초라는 기록이 있다. 이번 검토에서는 원시 로그를 확인하거나 재측정하지 않았다. 입력은 PDF·CSV 2개·TXT이며 XLSX 실측으로 표현하지 않는다.

수작업 84~85분은 측정이 아닌 가정이었다. 이를 시스템 실행 시간과 비교한 ‘실측 99% 절감’ 주장은 철회한다. 결과 확인·추출 수정·오탐 처리 시간도 포함해야 한다.

합성 샘플을 보고 정규화 규칙을 수정한 뒤 얻은 5/5 탐지 기록은 개발용 결과다. 미공개 문서 정확도나 현업 재현율을 뜻하지 않는다. 누락 정답은 해당 문서에 그 항목이 요구되는지 실무자가 확인해야 한다.

## 파일럿 측정

검토 완료 범위는 값 대조, 근거 확인, 판단 기록까지다. 실제 설계 수정 시간은 별도로 기록한다.

- 수작업 총시간: 문서 준비 + 값 탐색/대조 + 근거 확인 + 판단 기록.
- AI 지원 총시간: 준비 + 업로드/처리 대기 + 추출 확인/수정 + 결과 검토/오탐 처리 + 판단 기록.
- 작업자 투입 시간과 시스템 대기 시간을 별도로 기록한다.
- 절감률 = (수작업 총시간 - AI 지원 총시간) / 수작업 총시간 × 100.
- 동일인이 같은 문서를 반복하면 학습 효과가 생긴다. 가능하면 동등한 묶음의 검토 순서를 교차 배정하고 불가능하면 제한을 명시한다.

정밀도·재현율과 실패 문서도 함께 기록한다. 상세 양식은 [현업 검증 실행계획](06_현업검증_실행계획.md)을 사용한다.

## 비용 효과

일반 건설 재작업 비율 전체를 문서 불일치 비용으로 간주하지 않는다. 설계 변경·시공 오류에는 현재 시스템이 탐지할 수 없는 원인이 포함된다. 기존의 프로젝트 원가 대비 3.5~4% 및 탐지 기여율 50% 기반 절감액은 제품 효과 근거로 사용하지 않는다.

인건비 효과는 실측 절감 시간 × 실제 검토 횟수 × 시간당 비용에서 운영·유지 비용을 차감해 추정한다. 재작업 예방 효과는 확인된 개별 사례에 한해 탐지 가능 시점, 조치 가능성, 관련 비용을 검토하고 중복 집계를 피한다. 문서 크기와 무관하게 처리 시간이 유지된다는 가정도 사용하지 않는다.

## 발표용 문장

“합성 문서로 처리 흐름을 구현했으며, 실제 문서에서 오탐·누락과 엔지니어 검토 완료 시간을 측정해 효과를 검증할 계획입니다.”

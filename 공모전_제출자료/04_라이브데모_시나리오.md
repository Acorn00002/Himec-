# 라이브 데모 시나리오 (발표용)

> 소요: 약 3분 · 화면: 데스크톱 브라우저 전체화면

---

## 사전 준비 (발표 전날 + 당일 아침)

1. **백엔드 실행**: `cd backend && ./venv/Scripts/python -m uvicorn app.main:app --port 8000`
2. **프론트 실행**: `cd frontend && npm run dev` → http://localhost:3000
3. **Gemini 키 확인**: 루트 `.env` 의 `GEMINI_API_KEY` 존재 확인.
   당일 아침 `데모_샘플문서/` 4개 파일로 **한 번 리허설** 돌려서 이슈 5건 나오는지 확인.
4. **백업 플랜**: 아래 "장애 대비" 참조.

---

## 시연 스크립트

### ① 문제 제시 (말로, 15초)
> "펌프 하나의 정보가 기계 사양서, 전기 계산서, 도면, 설비 목록에 흩어져 있습니다.
> 이게 서로 맞는지 지금은 엔지니어가 눈으로 대조합니다. 그걸 자동화합니다."

### ② 새 프로젝트 + 업로드 (40초)
1. 랜딩 → **"새 프로젝트"** → 이름 `△△ 폐수처리 이송펌프 패키지`
2. 문서 업로드 화면 → `데모_샘플문서/` 의 **4개 파일을 한 번에** 끌어다 놓기
   - `01_기계장비_사양서.pdf` (한글 PDF)
   - `02_전기_부하계산서.csv` (영문 표)
   - `03_전기_단선결선도_주석.txt` (영문 도면 주석)
   - `04_설비_목록.csv` (한/영 혼용)
3. 각 문서가 **"AI 분석 완료"** 로 바뀌는 것 보여주기 → "형식·언어가 다 다른데 AI가 읽어냈습니다"

### ③ 교차검증 실행 (10초)
- **"교차검증 실행"** 클릭 → 대시보드로 이동

### ④ 대시보드 (30초)
- KPI: 문서 4 / 설비 3 / 이슈 5 / 높음 2~3
- **"AI가 하는 일"** 카드 짚기 → "추출은 AI, 판정은 검증 엔진"
- **AI 발견 사항** 리스트 → 첫 줄 `[높음] P-101 정격출력` 클릭

### ⑤ 이슈 상세 (60초) — 핵심
1. **문서별 값 비교** 표:
   - 사양서 15 kW / 계산서 15 kW / **도면 18.5 kW** (빨강)
   - "세 문서는 15인데 도면만 18.5. 사람이 도면 그리다 오기재한 전형적 케이스"
2. 값 클릭 → **원문 문장** 펼침 → "AI가 어디서 읽었는지 바로 확인. 환각 검증 장치"
3. **왜 중요한가?** → "정격출력이 틀리면 전류→케이블→차단기가 다 틀어짐"
4. **영향 가능 항목** 세로 흐름:
   `P-101 정격출력 → 전동기 정격전류 → 케이블 굵기 → 차단기 용량 → 배전반 부하`
   → "이 연쇄를 사람이 일일이 추적하기 어려운 게 세 번째 페인포인트"
5. **엔지니어 검토** → "조치 필요" 클릭 + 의견 입력 → 저장
   → "판단은 사람이. 시스템은 기록하고 리포트에 반영"

### ⑥ 마무리 (15초)
- 설비 탐색 → M-101 → 모델명 `SM-132M` vs `SM-132S` 짚기
  → "한 글자 차이. 132M과 132S는 정격이 다른 다른 모터. 눈으로 놓치기 딱 좋은 것도 잡습니다"
- "리포트 내보내기(PDF)" 버튼 → "검토 결과를 문서로"

## 시연에서 나올 이슈 5건 (예상)

| 위험도 | 설비 | 항목 | 내용 |
|---|---|---|---|
| 높음 | P-101 | 정격출력 | 15 / 15 / **18.5** / 15 kW |
| 높음 | P-101 | 정격전압 | 380 / 380 / **440** / 380 V |
| 높음 | P-101 | 케이블 규격 | 25 / 25 / **35** mm² |
| 중간 | M-101 | 모델명 | SM-132**M** / SM-132**S** |
| 낮음 | P-102 | 양정 | 사양서만 기재, 3문서 누락 |

*(Gemini 추출은 실행마다 미세하게 달라질 수 있음. 핵심 3건(정격출력·정격전압·모델명)은 안정적으로 재현됨.)*

## 장애 대비 (중요)

| 상황 | 대응 |
|---|---|
| **Gemini API 오류/지연** | 랜딩에서 **"데모 프로젝트 불러오기"** 클릭 → 큐레이션된 데모(M-101 등)로 전환. "실제 추출은 방금 보셨고, 이건 미리 준비한 데이터로 나머지 기능을 보겠습니다" |
| **인터넷 불가** | 데모 프로젝트는 API 없이 100% 동작. 라이브 업로드만 스킵 |
| **업로드가 느림** | 4개를 순차로. 사양서 PDF 먼저 (가장 임팩트) |
| **시간 부족** | ②③④ 스킵하고 데모 프로젝트로 바로 ⑤부터 |

> 발표 전 반드시: 데모 프로젝트 경로도 한 번 돌려서 상단 배지가 **"데모 데이터"** 로 뜨는지 확인 (실제 분석인 것처럼 보이면 안 됨).
